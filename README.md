# Observatorio Regional de Nariño

Plataforma académica de análisis económico y competitividad municipal.

**Autores:** Camila Guerrero · Geovanny Betancourt

## Contenido
- Estadística descriptiva completa
- Gráficos: barras, pastel, radar y vista 3D
- Matriz de correlaciones y modelo OLS
- Modelos predictivos (proyección 2030)
- Asistente temático

## Despliegue en Netlify
1. Sube el **contenido** de esta carpeta a la raíz de un repositorio GitHub.
2. Publish directory: `.`
3. Deploy.
